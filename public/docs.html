独立技能包包含SKILL.md、可运行Node.js入口、体检规则、点评与价格提案、素材与人设模块、浏览器执行器及使用说明。

免费功能长期可用，收费含标准与至尊。软件无试用期、优惠券或兑换券。

1. 下载与安装

需要Node.js 22.20+。下载技能包并对照首页公布的SHA-256核验，然后解压。把其中openlx-ctrip-hotel-ops目录放入智能体的技能目录。Codex默认为用户目录下的.codex/skills/。

cd openlx-ctrip-hotel-ops
npm ci
node scripts/ops.mjs doctor

仓库提供跨平台安装脚本scripts/install.mjs，支持安装、升级备份、回退和卸载保留业务数据。macOS及Linux安装验证范围见版本记录；Windows脚本已提供但尚未完成真实系统验证。

2. 初始化酒店与导入

node scripts/ops.mjs init --workspace ./hotel-work --hotel my-hotel --name 我的酒店
node scripts/ops.mjs import --workspace ./hotel-work --file /path/to/snapshot.json
node scripts/ops.mjs report --workspace ./hotel-work

数据结构见技能包references/runtime.md与examples/snapshot.json。示例标记MOCK；真实导出使用USER_EXPORT，后台读取使用LIVE并记录账号和来源。未知字段用null，不能用随机数据补图。

3. 登录与后台适配

node scripts/browser.mjs login --workspace ./hotel-work --channel ebooking
node scripts/browser.mjs login --workspace ./hotel-work --channel content

两个账号独立登记，使用专属Chrome目录。首次由你登录，关闭窗口后保存有效会话。当前未完成真实门店字段映射；浏览器执行器可以运行，但不能据此称所有账号均能自动操作。

完成实际字段与权限核验后，按运行说明填写账户适配。写动作核对门店、对象、旧值与批准内容，随后提交并回读；超时先查询，不盲目重试。

4. 点评、调价与定时运行

node scripts/ops.mjs reviews --workspace ./hotel-work
node scripts/ops.mjs prices --workspace ./hotel-work --file /path/to/pricing-policy.json
node scripts/ops.mjs approve --workspace ./hotel-work --id ACTION_ID --hash CONTENT_HASH
node scripts/ops.mjs execute --workspace ./hotel-work --id ACTION_ID
node scripts/ops.mjs run --workspace ./hotel-work
node scripts/ops.mjs pause --workspace ./hotel-work

免费好评自动回复需先开通动作授权并完成实际账户映射。无模型时使用保守规则与模板，语义不明内容进入人工确认。五星含投诉也需确认。定时运行可接操作系统调度器；设备关机、断网时不执行，恢复仅做一次追赶检查。

5. 至尊素材与包年人设

素材目录放置manifest.json，为每张图片记录酒店、场景、允许渠道、权利及人物授权。导入合格素材后生成草稿；文件生成、提交审核、公开可见分别记录。包年人设配置进入正文生成，实际人工交付以工单为准。

node scripts/ops.mjs assets --workspace ./hotel-work --folder /path/to/photos
node scripts/ops.mjs persona --workspace ./hotel-work --file /path/to/persona.json
node scripts/ops.mjs content --workspace ./hotel-work --topic 周末入住指南

至尊模块使用有效签名许可证。到期保留免费功能及历史数据；既有去推广署名报告不会重新加水印。

隐私与数据

门店快照、浏览器Profile、素材和生成报告默认保存在你的设备。官网不接收携程Cookie、客人身份资料或整份经营快照。请仅导入本次任务必需数据。

注册与登录使用现有OpenLX账号服务及其SMTP邮箱验证。官网保存携程产品的酒店绑定、订单、设备登记和服务工单，用于账号管理及权益履行。登录会话使用HttpOnly Cookie；后台操作授权与官网登录分开。

公开分享报告前请检查脱敏。使用自己的模型API时，应主动确认所发送事实与素材；默认生成不会把整个素材目录上传。数据导出在会员中心提供，联系支持可申请处理账号数据。
