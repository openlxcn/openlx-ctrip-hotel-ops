运行数据与密钥不进入Git。`OPENLX_SHARED_ROOT`是服务器现有服务的代码路径，加载原支付模块与配置；不会把微信业务代码或凭据复制进公开仓库。账户身份共享，携程套餐、订单、设备与人工权益独立。

本次没有真实携程门店或内容账号操作证据，因此对应适配不可宣称“全面可用”。模型适配代码和模拟验证不代表真实模型服务已验证，笔记提交执行器不代表账号实测完成。收款关闭由`SALES_ENABLED=false`明确控制，免费功能和报告照常运行。
