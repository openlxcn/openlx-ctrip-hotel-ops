# OpenLX 携程酒店运营助手

**先看清门店问题，再把每天的运营做扎实。**

点评要回，房价要看，房态要查，笔记还要发。忙了一天，哪些问题真正影响预订，往往还没有看清。

OpenLX 携程酒店运营助手，面向酒店、客栈与民宿，把门店资料、房型套餐、价格房态、订单和点评放进一份经营体检。告诉你发现了什么、依据在哪里、先处理哪件事，让每天的运营有清单、有记录、能复盘。

## 先拿到一份完整免费报告

导入门店真实数据，就能在本地生成可离线打开的 HTML 报告。全部发现和改进建议都可查看，不把关键问题藏在付费之后。点评按语义分流：符合规则的好评进入授权自动回复流程，差评、争议和混合评价确认最终文案后再处理。

当前 v0.1.1 已验证 macOS 与 Linux 安装、示例导入和报告生成。真实携程账号的字段、回复、改价、接单与笔记发布仍需逐项实测；导出的草稿只代表内容已准备，公开页面回读后才记为发布成功。

## 从体检，走向持续运营

标准版面向日常跟踪、基础价格策略、趋势复盘和去推广署名报告。至尊版进一步覆盖多信号收益策略、授权素材到携程笔记的内容生产与发布、首次定制服务；至尊包年保留人设蒸馏交付。

这些都是完整产品目标。当前尚未通过真实业务验收的项目继续开发，收费暂未开放，具体支持范围在官网逐项公开。

## 十二项优势，一个经营流程

1. 专属 Chrome，门店登录状态持续复用。
2. 全店经营体检，按影响和可执行性排列问题。
3. 完善酒店资料、设施与房型文案，让特色更清楚。
4. 房型、套餐与活动一起算账，看清实际到手。
5. 巡检房态与库存异常，形成可核对的策略。
6. 结合预订进度和价格底线，给出有依据的调价建议。
7. 跟踪真正可比的同行，比较同日期、同权益的价格。
8. 提前整理节假日、活动和周边需求日历。
9. 从订单异常和入住需求生成今日运营清单。
10. 好评按规则授权回复，差评确认，提炼服务改善建议。
11. 至尊版从真实授权素材生产笔记并按授权发布，包年增加人设蒸馏。
12. 完整 HTML 报告，把发现、动作和回读结果连起来。
